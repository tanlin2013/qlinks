Cycle diagnostics

Import-time SCCs use only eager module-scope imports and are split into API/re-export cycles (package initializers or known compatibility facades) versus implementation cycles. The secondary “type/lazy static” entries appear only when TYPE_CHECKING and function-local imports are included, so intentional typing or cycle-breaking imports are not mistaken for eager import cycles. Package-level import-time cycles are reported separately in the summary.

Architecture guardrails

The report mirrors the broad dependency rules in AGENTS.md: caging/open-system separation, neutral local structure, temporary-facade isolation, and the focused local-search ordering. The dedicated pytest architecture tests remain the blocking source of truth for CI.

Interpretation

Treat fan-in/fan-out and line count as navigation aids, not quality scores. A large scientific module can be legitimate; the strongest warning signs are cross-layer violations, strongly connected components, and high coupling that crosses responsibility boundaries.
